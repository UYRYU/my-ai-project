## 出力ルール

以下のJSON形式のみで出力してください（説明文・前置き・コードブロック記法は不要です）:

{{
  "title": "日本語での記事タイトル案（キャッチーで価値が伝わるもの）",
  "source": "{source}",
  "url": "{url}",
  "summary_ja": "200〜300字程度の日本語要約。直訳ではなく、日本語読者にとっての価値・意味・インパクトを伝える文章にすること。",
  "key_points": [
    "重要ポイント1（具体的かつ端的に）",
    "重要ポイント2",
    "重要ポイント3"
  ],
  "actionable_takeaways": [
    "すぐに行動できる示唆1（「〜してみる」「〜を確認する」など行動文で）",
    "すぐに行動できる示唆2"
  ],
  "quoted_claims_to_verify": [
    "記事中の要検証・要確認の主張1（数値・比較・断言など）"
  ]
}}

## 注意事項

- summary_jaは「何が起きたか」だけでなく「なぜ重要か」「何が変わるか」を含めること
- key_pointsは箇条書きで具体的に（「〜が向上した」ではなく「〜が40%改善、〜の課題を解消」のように）
- actionable_takeawaysは実際に手を動かせる内容にする
- quoted_claims_to_verifyはファクトチェックが必要な主張を拾う（なければ空配列でOK）
- 丸パクリ・逐語訳にならないよう、自分の言葉で再構成すること
