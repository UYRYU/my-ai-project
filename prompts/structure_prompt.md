あなたは海外AI情報を日本語読者向けにコンテンツ設計する専門家です。

以下の要約済み記事を「思想」「実装」「示唆」の3つのレンズで再構造化してください。

## 入力（要約済み記事）

タイトル: {title}
ソース: {source}
URL: {url}

日本語要約:
{summary_ja}

重要ポイント:
{key_points}

活用示唆:
{actionable_takeaways}

---

## 出力ルール

以下のJSON形式のみで出力してください（説明文・前置きは不要）:

{{
  "angle": "この記事の切り口・視点（例：「コスト革命としてのAI推論効率化」「LLMによるソフトウェア開発の民主化」）",
  "audience": "想定する主な読者層（例：「スタートアップのプロダクトマネージャー」「AIに関心のある文系ビジネスパーソン」）",
  "core_insight": "この記事から得られる最も重要な洞察を2〜3文で。「思想」レンズ：背景・文脈・哲学的含意を含む。",
  "implementation_hint": "「実装」レンズ：具体的にどう使うか・どう試すかの示唆を2〜3文で。技術者でなくても理解できる表現で。",
  "note_outline": [
    "## はじめに：なぜ今これが重要か",
    "## 要点整理：3つのポイント",
    "## 背景と文脈：この変化が起きている理由",
    "## 実装・活用への示唆：明日から使えるアクション",
    "## まとめ：この先に何が来るか"
  ],
  "x_hooks": [
    "X投稿用フック案1（問いかけ型・読者が気になる問いで始まる）",
    "X投稿用フック案2（事実型・驚くべき数字や事実で始まる）",
    "X投稿用フック案3（洞察型・逆張りや意外な視点で始まる）"
  ]
}}

## 注意事項

- angleは「〜について」のような抽象的な表現は避け、価値判断を含む表現にする
- core_insightは「何が変わるのか」という変化の軸を明確にする
- implementation_hintは非エンジニアにも読める表現で書く
- note_outlineの各章名は、読者が「読みたい」と思えるタイトルにする
- x_hooksは3パターンとも違うトーン・アプローチにする
